# 生命周期、追加式审计与敏感数据删除

申请生命周期（草稿 → 处理中 → 待复核 → 辅助审查完成 → 已归档）在 API 层统一强制：所有输入型端点共享可变更状态守卫（`draft`/`processing`/`pending_review`），已完成或已归档申请对上传、重试、字段确认、映射、豁免与正式执行一律返回 409，直接 URL/API 尝试无法绕过。审计采用追加式 `audit_events` 表，事件只插入、不修改、不删除，且不携带材料正文、提示词正文或模型响应正文；云调用受限审计内容（脱敏请求/响应）仍单独存放在 `cloud_extraction_calls`，仅负责人可见。整笔硬删除仅限管理员，分两阶段（理由 → 短期确认令牌），级联清除 MinIO 原件与全部敏感派生数据，仅保留不含业务敏感内容的墓碑；删除失败的 MinIO 对象记录在墓碑上，保证部分失败可见、可恢复。
